# Customer Management API

REST API developed with Node.js, TypeScript, MongoDB and TypeORM.

## Features

* Customer CRUD operations
* MongoDB integration
* Swagger documentation
* Docker support

## Technologies

* Node.js
* TypeScript
* Express
* MongoDB
* TypeORM
* Docker

## Running the project

```bash
npm install
docker-compose up --build
```

API: `http://localhost:4444`

Swagger: `http://localhost:4444/swagger`
